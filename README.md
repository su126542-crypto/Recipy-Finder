# RecipeFinder

RecipeFinder is a React-based web application that helps users search for meals, view recipe details, and organise their meal plans. The application uses TheMealDB API to retrieve recipe information.

## Live Website

[Open RecipeFinder](https://su126542-crypto.github.io/Recipy-Finder/)

## GitHub Repository

[View the source code](https://github.com/su126542-crypto/Recipy-Finder)

## Features

- **Recipe Search:** Search for recipes using meal names or ingredients.
- **Recipe Details:** View recipe information, ingredients, measurements, and cooking instructions.
- **Save Recipes:** Save recipes for later using browser local storage.
- **Meal Planner:** Access the meal planner screen to organise meals.
- **Responsive Design:** The application is designed to work on desktop, tablet, and mobile screen sizes.
- **Navigation:** Move between the Home, Recipe Details, and Meal Planner screens.

## External API

RecipeFinder uses the free TheMealDB API to retrieve meal and recipe information.

API website: https://www.themealdb.com/api.php

The application uses JavaScript `fetch()` and `async/await` to request and process recipe data from the API.

## Installation and Setup

To run the project on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/su126542-crypto/Recipy-Finder.git
   ```

2. Open the project folder:

   ```bash
   cd Recipy-Finder
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Build for Production

To create a production build, run:

```bash
npm run build
```

## Deployment

The application is deployed using GitHub Pages.

To deploy an updated version, run:

```bash
npm run deploy
```

## Project Purpose

The purpose of this project is to apply the concepts learned during the Web Programming course, including React components, state management, routing, API requests, asynchronous JavaScript, responsive design, and browser local storage.
